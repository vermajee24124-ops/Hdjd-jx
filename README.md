# AI Power Game Factory build workspace

This public repository is a temporary build workspace for a modified iappyxOS build. The workflow fetches the upstream open-source iappyxOS source at build time, applies the local multi-provider/AI-Fleet patch, and publishes the resulting Android APK as a GitHub Actions artifact.

No API keys are stored in this repository. Enter keys inside the app on the device.

Build trigger: functional APK pipeline enabled.
